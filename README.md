# QGIS Flood Mapping using Sentinel-1 SAR

## Overview
This project demonstrates flood extent extraction using Sentinel-1 SAR imagery in QGIS. Pre- and post-flood SAR images are processed to identify inundated regions across multiple districts of Sri Lanka.

---

## Study Areas

- Gampaha
- Kalutara
- Matara
- Ratnapura

---

## Methodology

1. Download Sentinel-1 GRD imagery
2. Radiometric Calibration
3. Speckle Filtering
4. Terrain Correction
5. Image Thresholding
6. Flood Mask Generation
7. Export GeoTIFF
